# Security Policy

## Responsible disclosure

SafeIdent Wallet ile ilgili olası bir güvenlik veya gizlilik problemi fark ederseniz ayrıntıları public issue içinde paylaşmayın.

GitHub profili üzerinden geliştiriciyle özel iletişim kurun ve mümkünse şu bilgileri ekleyin:

- Etkilenen akış veya bileşen
- Problemi yeniden oluşturmak için gereken adımlar
- Beklenen ve gözlenen davranış
- Olası etki
- Varsa önerilen düzeltme

Bu vitrin deposu kaynak kod barındırmaz. Kaynak depoya ilişkin hassas ayrıntılar, anahtarlar, kişisel veriler veya çalışan exploit örnekleri public olarak yayınlanmamalıdır.
